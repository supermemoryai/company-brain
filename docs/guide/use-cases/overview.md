# What you can do

Real scenarios for Company Brain, from Slack answers to sandbox debugging.

Company Brain is most useful when it shows up in the work you already do. These walkthroughs are short, concrete scenarios: each one is a real exchange, what the bot is actually doing under the hood, and which concept page to read if you want the full picture.

## Works today

- **[Automatic support](support.md):** customer question in Slack; Company Brain chimes in with the answer.
- **[Incidents and downtime](incidents.md):** "Is prod down?" answered from live Sentry, plus scheduled digests.
- **[From support ticket to code fix](support-escalation.md):** a Plain ticket triaged in Slack, handed to a coding agent.
- **[Meeting recall](meeting-recall.md):** "What did we decide with Acme?" from meeting notes.
- **[Answering from docs](knowledge-recall.md):** roadmaps, specs, and handbooks, asked in plain language.
- **[Acting in tools](acting-in-tools.md):** list open PRs, create a Linear issue, under your own account.
- **[Greeting new teammates](greeting.md):** welcome DM and first answer, activation on day one.
- **[Sandbox debugging](sandbox-debugging.md):** actually run the failing test in an isolated workspace.

## Not yet

- **[Long-horizon research](long-horizon-research.md):** questions that need many sources synthesized into one answer.
- **[Meeting scheduling](meeting-scheduling.md):** find free time and send a calendar invite from Slack.

If you're still setting things up, start with [What is Company Brain?](../overview.md) and work through the concept pages first; the walkthroughs assume those ideas.
